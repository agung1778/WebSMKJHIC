🤖 AI Chatbot Widget (Plug & Play)

Halaman ini adalah demo integrasi chatbot mandiri. Cukup dengan menambahkan file chatbot.css dan chatbot.js, tombol floating chat di pojok kanan bawah akan langsung muncul!

📋 Cara Copas ke Website Apapun:

Tambahkan kode berikut sebelum tag penutup </body> di file HTML / PHP / Blade website Anda:

<!-- 1. CSS Widget -->
<link rel="stylesheet" href="/path-ke-folder/widget/chatbot.css">

<!-- 2. Konfigurasi Opsional -->
<script>
    window.AiChatbotConfig = {
        endpoint: '/path-ke-folder/api/chat.php',
        title: 'Nama Bisnis Anda',
        subtitle: 'Online • Siap membantu',
        welcomeMessage: 'Halo! Ada yang bisa kami bantu hari ini? 😊'
    };
</script>

<!-- 3. Script JS Chatbot -->
<script src="/path-ke-folder/widget/chatbot.js"></script>

💡 Uji Coba:

Klik tombol lingkaran biru berikon pesan di pojok kanan bawah halaman ini untuk mencoba berbicara dengan AI Chatbot!
